# Amaliy Ish

HTML va CSS yordamida yaratilgan sodda va zamonaviy **navigatsiya paneli (navbar)** loyihasi. Ushbu loyiha frontend dasturlashni amaliyotda mustahkamlash maqsadida tayyorlangan.

## 📋 Loyiha haqida

Bu amaliy ish quyidagilarni o'z ichiga oladi:

- Logotip va sarlavha
- Menyu havolalari (Bosh sahifa, Xizmatlar, Loyiha haqida, Aloqa)
- "Kirish" tugmasi (CTA button)
- Sichqoncha olib borilganda (hover) chiroyli effektlar
- Mobil qurilmalar uchun moslashuvchan (responsive) dizayn

## 🛠 Ishlatilgan texnologiyalar

- **HTML5** — sahifa tuzilishi uchun
- **CSS3** — dizayn va uslublash uchun (Flexbox, media query, transition)

## 📁 Fayllar tuzilishi

```
amaliy-ish/
├── index.html   # Sahifaning asosiy HTML fayli
├── style.css    # Sahifa uslublari (CSS)
└── README.md    # Loyiha haqida ma'lumot
```

## 🚀 Loyihani ishga tushirish

1. Repozitoriyni klonlang:
   ```bash
   git clone https://github.com/h0310303-a11y/amaliy-ish.git
   ```
2. Loyiha papkasiga o'ting:
   ```bash
   cd amaliy-ish
   ```
3. `index.html` faylini istalgan brauzerda oching.

## 📱 Responsive dizayn

Sahifa 768px va undan kichik ekranlarga moslashtirilgan — navbar padding va shrift o'lchamlari kichik ekranlar uchun avtomatik o'zgaradi.

## 👤 Muallif

Ushbu loyiha o'quv maqsadida, amaliy topshiriq sifatida tayyorlangan.
